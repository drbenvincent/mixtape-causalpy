Chapter 9: Difference-in-Differences

Causal Inference: The Mixtape → CausalPy

Mixtape chapter: Difference-in-Differences

CausalPy method: StaggeredDifferenceInDifferences for the castle-doctrine panel. DifferenceInDifferences estimates one group-by-post interaction. It is not the castle result.

Overview

Adoption dates in the castle-doctrine panel are not a single year. A two-group, two-period coefficient is the wrong estimand for that design, and it is not what this page reports.

The required fit below is the Borusyak, Jaravel, and Spiess imputation estimator (Borusyak et al. 2024). The untreated outcome is cp.pymc_models.LinearRegression on state and year fixed effects. It is not Cheng and Hoekstra’s two-way fixed-effects coefficient (Cheng and Hoekstra 2013), and it is not castle_1.py.

Snow, the minimum wage, block bootstrap, clustering, the Affordable Care Act, and maternity benefits have no script on this page. No dataset is added for them.

Castle doctrine

castle.dta is a state-year panel. treatment_date is the adoption year, and it is missing for states with no recorded adoption. The outcome used here is l_homicide, the log homicide rate.

DifferenceInDifferences estimates a single group-by-post interaction. That is not this panel, and it is not used as the result.

The file stores a missing treatment_date for 29 states. StaggeredDifferenceInDifferences rejects missing treatment times. It does not read a missing date as never-treated. Those dates are recoded to np.inf, the class default for never-treated, before the fit. The states stay in the panel and are the never-treated controls. None are dropped.

There is no already-treated cohort in the first year. The panel starts in 2000 and the earliest recorded adoption is 2005.

Imputation event-time contrasts

The required formula is state and year fixed effects. C() accepts the numeric year column, so year is not recoded to a string. The 1 in the formula is the intercept column of the design matrix. cp.pymc_models.LinearRegression fits that matrix. It does not add a second intercept.

post is an absorbing 0/1 column in the file. It is not passed as treated_variable_name. The absorbing-treatment check runs only when that argument is passed. l_homicide has no missing values, so there is nothing for a missing-outcome check to drop. The class’s missing-value check on a treated column is about the treatment indicator, not the outcome.

StaggeredDifferenceInDifferences has no weight argument. popwt is not passed, and this is not the book’s population-weighted least squares.

Draws, tune, chains, and cores are the library defaults. sample_kwargs keeps progressbar, random_seed, and target_accept=0.95. That target_accept is the one raise already in this file, after a default-length render with max r-hat 1.0375 and min bulk ESS 73. nuts_sampler is omitted, so the installed nutpie sampler is selected.

bayes_result = cp.StaggeredDifferenceInDifferences(
    castle,
    formula="l_homicide ~ 1 + C(state) + C(year)",
    unit_variable_name="state",
    time_variable_name="year",
    treatment_time_variable_name="treatment_time",
    never_treated_value=np.inf,
    model=cp.pymc_models.LinearRegression(
        sample_kwargs={
            "target_accept": 0.95,  # default-length render: max r-hat 1.0375, min bulk ESS 73
            "progressbar": True,
            "random_seed": 42,
        }
    ),
).fit()

att is the posterior mean of the unit-averaged imputation contrast at that event time: observed log homicide minus the untreated prediction. It is not normalized to a zero reference period. The constructor’s reference_event_time defaults to −1 and is reserved for plots; it does not subtract that cell from the others. Event time −1 is -0.017, not zero. Event time 0, the adoption year, is +0.061 log points, from 21 state-years. Its 94% interval is [+0.014, +0.106]. att_lower and att_upper are the 3rd and 97th percentiles of that contrast. They are not residual standard errors, and they are not standard errors clustered by state.


That event-time 0 number is not Cheng and Hoekstra’s two-way fixed-effects coefficient. This page does not estimate that coefficient, so the two are not compared.

NoteWhat this fit is not







This is not castle_1.py. That script is population-weighted least squares of log homicide on post, demographic and spending covariates, region-quarter indicators, state trends, and state and year effects, with standard errors clustered by state. This page does not estimate that coefficient. The class has no weight argument, so popwt is not used.


castle_2.py is an event study: leads 1–9 and lags 1–5, with lag0 omitted, plus region-quarter indicators and state and year effects. It is population-weighted least squares, clustered by state. It does not include castle_1.py’s covariate list. castle_3.py and castle_4.py plot those weighted least-squares estimates. CausalPy does not implement that regression. The imputation table above is not those figures.


castle_5.py is empty. The R script decomposes l_homicide ~ post with the Bacon decomposition. It is not run.


PR #584 is an open proposal for a common-timing event study. It is not this staggered design, and it is not a castle-doctrine specification.
















NoteBacon decomposition and triple differences







A Bacon decomposition would split a two-way fixed-effects coefficient into timing comparisons. CausalPy does not implement it, and none is computed. This file also has no already-treated cohort in 2000.


Triple differences (abortion_ddd.py, abortion_ddd2.py) are not in CausalPy. The write-up is proposals/proposal_triple_diff.md. That proposal is not a Bacon decomposition.












Abortion legalization


The book’s abortion exercise is a two-way fixed-effects regression. Treatment is an early-repeal indicator interacted with year, on state-years from 1985 to 2000, with state and year effects and controls. A split of the sample at 1993 is not that design. It is not used here, and the regression is not fit.

NoteAbortion scripts are not run







abortion_dd.py and abortion_dd2.py are the two-way fixed-effects regressions above. DifferenceInDifferences estimates one group-by-post interaction, which is not those regressions. Neither is run on this page.










Summary


The required estimator is the Bayesian imputation for castle doctrine. It is still not castle_1.py. The two-way fixed-effects castle coefficient, the weighted least-squares event study, the Bacon decomposition, the abortion two-way fixed effects, and triple differences are callouts. They are not counted as completed reproductions of those scripts.
